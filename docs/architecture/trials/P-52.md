# P-52

Batch: none

## Question

Can the Controller's installation token, with the Variables permission at repository read alone, read `FACTORY_PAUSED` on a repo it acts in, and the org's `FACTORY_PAUSED` shared with that repo, and by which route?

## Pass

The repo's is read, and the org's by at least one route, its own endpoint or the repo's list of the org's variables, with its name and value; otherwise the Controller needs the organization's Variables permission, or the pass reads the org's Pause another way. **Passed** on 2026-10-27 (`trials/P-52.json`), at the Maintainer's terminal with the Controller's key, one token minted and revoked. Its permissions named `actions_variables` at read and nothing of the org. The canary's `FACTORY_PAUSED` answered 200, `false`; the org's own endpoint refused it, 403, asking for `organization_actions_variables`; the canary's list of the org's variables answered 200 and named the org's `FACTORY_PAUSED`, `false`. So the pass reads the org's Pause through the repo's list. A token minted narrowed to exactly `metadata: read` and `actions_variables: read`, the names the pass asks for, was answered with those and no other, and read both, 200, on 2026-10-27 (`trials/P-52.narrowed.json`)
