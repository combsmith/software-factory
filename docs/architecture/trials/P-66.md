## Question

When a pull request that conflicts with its base is enqueued (`enqueuePullRequest`, with the head it expects), does the merge queue refuse the enqueue, or take it and drop it? When a queued pull request's base moves into conflict with it, does the queue drop it? What does each leave on the timeline, in `mergeable` and `mergeStateStatus`, and in the queue's entry?

## Pass
