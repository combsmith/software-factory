## Question

When a dependency bot updates an Action's pin in a workflow file, does it open the pull request and push its head under its own `[bot]` identity, so that the port's class for it is `dependency`?

## Pass

Yes, with the bot as author and last pusher. If a person's push follows, the class is read as any other change's (decision 0026). **Passed** on 2026-10-21 (`trials/P-45.json`): Dependabot opened canary pull request 50, moving actions/checkout from v7.0.0 to v7.0.1, and pushed its head, both as `dependabot[bot]`, a Bot, id 49699333; GraphQL names the same account `dependabot`, so the port reads it by id and type
