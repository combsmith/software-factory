# NNNN. The Kernel calls nothing it is given but `_decision`, and what fills `_decision` is a Kernel function

Status: accepted. The Factory Builder's story of 2026-11-06, issue 588, "The Kernel calls nothing it is given but `_decision`: check_purity refuses a call of a parameter". It widens decision 0001's rule, that the Kernel does no I/O, from what the Kernel imports and names to what it calls.

## Decision

| What | Decided | Because |
|---|---|---|
| The rule | Inside `kernel/`, `tools/check_purity.py` refuses a call of a parameter, unless `CALLABLE_PARAMETERS` names it (`_decision` alone); a call of a name the function binds otherwise, from `context.get` or a loop, say; a method call whose name `BUILTIN_METHODS` does not list, unless it is a call of a function of a module of the Kernel's; a call of a name imported from outside the Kernel, or that no Kernel module defines; a call of anything but a name or an attribute; and a decorator, which calls what it names. A function's decorators, defaults and annotations, and any name they bind, are read in the scope that defines it, its body inside it. A function or lambda the function defines, a function of the module or one it imports, and a builtin may be called. A name bound two ways, such as a parameter that a nested `def` replaces, counts as a value | A Kernel function handed a function could read the network or the clock through it, while every import and name it uses passed the check. The Kernel is given values, not ways to get them |
| What is handed to be called | What a call gives as `key=`, and `map`'s or `filter`'s first argument, is held to the same rule: a lambda, a function the Kernel defines or imports, or a method by a listed name. Nothing is spread with `*` or `**` into `map`, `filter`, `sorted`, `max` or `min`, and `iter`, which calls its first argument when given a sentinel, joins `FORBIDDEN_NAMES` | Each of these calls what it is handed, so handing a parameter to one would be a call of it |
| How the Kernel imports itself | A module of the Kernel's is imported as `from kernel import x`, `from kernel.x import f`, `import kernel.x as x`, or relatively, and is read as Python reads it, a package's `__init__.py` too. `import kernel.x` without a name and `import *` are refused, and a module is named only to read a name of it, never kept as a value, however many modules it is re-exported through. `typing` leaves `ALLOWED_IMPORTS`, so the Kernel imports only `__future__` and itself | So that every call into the Kernel's own code can be told to be one, and what fills `_decision` is read however the function that takes it is reached. `typing` reaches `sys` and an `eval` of its own, and the Kernel imports nothing from it on `main` |
| `BUILTIN_METHODS` | An exact list of the sixteen methods of built-in types the Kernel calls on `main`: `append`, `casefold`, `count`, `endswith`, `find`, `fromkeys`, `get`, `items`, `join`, `partition`, `pop`, `rstrip`, `split`, `startswith`, `update`, `values`. A name is added only as the Kernel needs it | A method of another name, such as `read`, is the value's own and may do anything. A list, not a pattern, so that each method is a choice someone made |
| What fills `_decision` | Only a function at a module's top takes `_decision`, by its name or its place, never as `*` or `**`. It is only ever called, never named in another way. Whatever fills it, by its name or its place (by its place alone where it is positional-only), is a function defined at the top of a Kernel module, followed through any module that imports it, or the caller's own `_decision`. A value, or a name no module defines, reached through a module is not one. A spread that may fill it is refused | The issue would have held this with a test. The check holds it on every module, so a new caller cannot hand in a function the check would refuse to see called |
| `BUILTIN_CALLS` | An exact list of the builtins the Kernel may call: those it calls on `main`, and `map` and `filter`. A call of any other builtin, or handing one to be called, is refused | A builtin such as `__build_class__` calls what it is handed, and others reach past the Kernel. A list, as for the methods |
| `callable` | Joins `FORBIDDEN_NAMES` | The Kernel never asks whether a value is a function, and has no need to. It uses neither `iter` nor a decorator either |
| On `main` | The check passes as it is. The functions that take `_decision` are the brakes' seven and `kernel/derive.py`'s `run_deferral`, and every call of one passes `kernel/decide.py`'s `_decision`, `kernel/issue.py`'s, or the caller's own | Confirmed across `kernel/` before the rule was written: no other parameter, bound value or method is called |
| Not held: a handed value's own special methods, such as iterating it, comparing it or making it a string | The facts the Kernel is given are JSON, built by the controller and held to `schemas/facts.schema.json`. Values of that kind have no methods of their own. `tests/test_decide.py::test_the_same_inputs_give_the_same_decision` still holds that the same inputs give the same Decision |
| Not held: a method whose name is on the list, called on a value that is not of a built-in type | The check reads the syntax tree and does not know types. The facts are JSON, as above |

## Why

Decision 0001 keeps all I/O in adapters, and `tools/check_purity.py` held that by what the Kernel imports and the names it uses. A function handed in as an argument slipped past both: `def decide(facts, fetch=None): ... fetch()` passed while the caller handed it a reader of the network. The Kernel calls one value it is given, Admission's maker of a Decision, and every caller fills that with a Kernel function. So the check allows that one by name, holds what fills it, and refuses every other call that is not of the Kernel's own code or a builtin.

## Boundaries

| Boundary | Check |
|---|---|
| A call of a parameter other than `_decision`, of a value bound from an argument or a loop, of a method not on the list, of a name imported from outside the Kernel, or of what an expression gives, is refused, and so are a decorator, handing one to be called or spreading into a builtin that calls, `callable`, `iter`, an import of `typing`, a Kernel module imported unnamed or by `*`, and a module kept as a value, re-exported or not. A function's defaults and annotations are read where it is defined. `_decision`, a local function or lambda, a module's function, a listed method and a builtin pass | `tests/test_tools.py::test_the_kernel_calls_nothing_it_is_given` |
| What fills `_decision` is a Kernel function or the caller's own, by its name or its place, however the function that takes it is imported: relatively, from a package, as a module's function of a listed method's name, or through a module that imports it. A function that takes it is at a module's top and is only called | `tests/test_tools.py::test_what_fills_a_decision_maker_is_a_kernel_function` |
| On the Kernel as it stands, the functions that take `_decision` are named, and each call of one fills it with a Kernel function | `tests/test_tools.py::test_each_decision_maker_the_kernel_fills_is_a_kernel_function` |
| Each of these rules has a mutant that a test kills | `tools/mutants.py` |
