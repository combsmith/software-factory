# 0001. One repo, and a Kernel that does no I/O

Status: accepted. Source: decision 1 of `docs/architecture/adr/0013-factory-mvp-reference-architecture.md`,
as it stood on 2026-10-11. That file records how this was reached; this one is the rule.

## Decision

The Factory lives in this repo alone: Lifecycle, Role manifests, schemas, configuration, Kernel,
adapters, Harness, Controller, release tooling and their tests. The Kernel is Python 3 with the
standard library only. All I/O is in adapters. Shell is step glue.

## Why

A decision that does no I/O can be run thousands of times against a fake world before it is
trusted with a real one. A repo that reads nothing from another can be verified from one commit.

## Boundaries

| Boundary | Check |
|---|---|
| No module under `kernel/` opens a file, a process, a socket or the environment, or reads a clock | `tools/check_purity.py` |
| A module under `kernel/` is UTF-8 and declares no other encoding, so that the text the check and every reader parse is what Python runs; one that declares another, or whose bytes are not UTF-8, is refused (issue 992) | `tools/check_purity.py`, `tests/test_tools.py::test_the_kernel_is_read_as_python_runs_it_utf_8_alone`, mutant: "a declared encoding is read as UTF-8", mutant: "bytes that are not UTF-8 are replaced" |
| What Python imports as `kernel` is what the check read: `kernel/` and each folder of it has its `kernel/__init__.py` or the folder's own, holds source and an `AGENTS.md` alone, and is no link; and the Kernel reads nothing off a value but a name of a module of its own, where an import by the Kernel's name binds it, never a relative one or another module's re-export, or by a built-in type's method it calls, so no generator's frame hands it a builtin: "The purity check does not ask that kernel/ is the package Python imports: a kernel.py at the root, or a compiled module beside a source, runs unread" (issue 851) | `tests/test_tools.py::test_the_kernel_is_the_package_python_imports_and_reads_nothing_off_a_value`, `tools/check_purity.py`, mutant: "the Kernel is not held as the package Python imports, and reads what it likes off a value" |
| Six older ways past the Kernel's rules are refused: a `frozenset` at a module's top or as a default whose argument calls anything but another such constant, iterates, yields, unpacks with `*` or `**`, formats a value into text (which could write a set's order there), or names anything but a name bound at the module's top (and, for a default inside a function, not bound again anywhere in the statement that holds it, by a parameter, an assignment or an import), which could keep a list a generator yields or a local value, and any binding of the name `frozenset`, and an assignment at a module's top to anything but names, or a tuple or list of them unpacking anything but a tuple written out in its own shape, which could keep a starred name's list or a set's elements in the hash seed's order; site's builtins (`license`, `copyright`, `credits`, `help`, `exit`, `quit`) as values; an import of a module of the package that no file read is, or of a folder that is there but read as no package (one that holds a `.git`, which the walk leaves out, among them), which Python imports before a file of its name, or a name a from-import takes, absolute or relative, that is neither a module read nor a name its module binds but by importing it; the package itself imported under a name, which is no module of it; a relative import from above `kernel/`; and `with`, `await`, `yield from`, `async for`, an async comprehension and `assert`, each of which calls a method of a value it is handed. A `for` over a value, or `next()` of one, is not refused: what the Kernel is handed is a fact (issue 909) | `tools/check_purity.py`, `tests/test_tools.py::test_six_older_ways_past_the_kernels_rules_are_caught`, mutant: "a frozenset may keep what a call in it gives", mutant: "an import no file answers to is read as one", mutant: "a statement that calls a method of a value passes", mutant: "a default inside a function names the module's names, whatever the function binds", mutant: "a starred name at the top keeps its list" |
| Every decision the simulated worlds' fixed seeds reach, and its inputs, are the same, text for text, made in four processes under four hash seeds, so a set of strings iterated into them shows (issue 1137). Limit: a decision no seed reaches, or a set whose order the four seeds happen to share, is not caught | `kernel/derive.py`, `tests/test_decide.py::test_the_same_inputs_give_the_same_decision_under_another_hash_seed`, mutant: "the open gates' ids are read in a set's order" |
| No module under `kernel/` or `guards/` writes a function into text, by `str`, an f-string or `%`, which gives its address in memory (issue 1137). Limit: a good-faith mark, as decision 0215's limit row says; a function reached through another name, a container or a parameter is for review | `tools/check_purity.py`, `tests/test_tools.py::test_the_kernel_writes_no_function_into_text`, mutant: "str of a function passes" |
| No module under `kernel/` or `guards/` writes into text, by `str`, an f-string, `%` or `.join`, a map, filter, zip or enumerate object or a generator expression, which gives its address, or a set, which gives the hash seed's order, where it is made: in a container, a set operation, a pick or a comprehension too, and a set through `list`, `tuple`, `*` or a comprehension's `for` (issue 1202). Limit: a good-faith mark, as decision 0215's limit row says; such a value held by a name, made by a function the Kernel calls, passed through another call, or picked out of or added to a container is for review | `tools/check_purity.py`, `tests/test_tools.py::test_the_kernel_writes_no_address_or_sets_order_into_text`, mutant: "a set may be written into text" |
| Nothing here is installed: no dependency manifest, and every import is the standard library or this repo | `tools/check_repo.py` |
| No code or data file names the proof-of-concept repo; nothing is fetched from it | `tools/check_repo.py` |
| A `run:` block in a workflow is at most ten lines and holds no decision | `tools/check_workflows.py` |
| The repo's settings are what the design rests on: the check is required, secrets are scoped to an environment, the default token only reads | waiting on `adapters/settings.py` |
