# NNNN. The writes check reads a name back through what it is given, and holds an object's class, another module's names set from outside, sys and loads reached other ways, code run from text and a command a shell runs; a runner's helper stays the review's

Status: accepted. The Factory Builder's story of 2026-11-08, issue 640, "check_writes: routes still open after issue 596, a runner's helper, a class or instance reached through another name, sys.modules by getattr", raised by the reads of issue 596, "check_writes: further ways a write could be reached past the check, written to hide it". It amends decision 0167's row "Still not held".

## Decision

| What | Decided | Because |
|---|---|---|
| A name read back through what it is given | `tools/check_writes.py` reads what an attribute or a key is set on back through the names it is given: a module's constant that is another name, `P = Port` or `D = other.TABLE`, and a name a function or a function round it is given, by a default, an assignment, a walrus or a tuple's part at its place, `cls=Port`, `c = cls`, `a, b = Port, 1`. `vars(m)` is m. A name a nested scope binds is not the function's own | Each sets on a class, or on another module's name, as surely as the name itself does |
| An object's class | An attribute set on `type(x)`, `x.__class__`, `x.__mro__` or `x.__bases__`, or on what holds one, is refused, and so is `setattr` named as a value and `__setattr__` | Which class an object has is a value the syntax does not give |
| A class's attribute, set other ways | A `for`, a `with` or a comprehension that sets an attribute sets it as an assignment does. A function under an `if` or a `try` is a function, and a nested `def` or `class`, or a caught exception's name, shadows a text constant | Decision 0167 refused an attribute set on a class from outside by an assignment alone |
| Another module's names | An attribute or a key set, or a container filled by `update`, `append` or their kind, from another module on what a module of the repo's defines or is, an instance, a dict, a function or the module itself, is refused, to anything but text. PATCHERS names who may, with each name: `tools/make_corpus.py`, which sets `sim.world.decide` to its recorder. A new one is the Maintainer's to allow, and an entry for a name its file does not set is refused | A caller reads what a module's own code gives its names; what another module sets on them is a value the syntax does not follow |
| sys and loads reached other ways | Refused as a load by name: `.modules` read of anything; `sys` named as a value, `s = sys` or `getattr(sys, 'modules')`; its namespace, `sys.__dict__`; `sys` reached through another module, `os.sys`, or imported from one, `from os import sys`; `getattr` given `"sys"` or `"modules"`, or a key `"sys"` or `"modules"` read, as a literal; `__builtins__` and `__import__` as an attribute; and pkgutil and runpy, imported | Each reaches a module by its name, which decision 0167 refuses by its plain names |
| Code run from text | `exec`, `eval` and `compile`, named where the module binds no name of its own so, and `exec` or `eval` as an attribute, are refused. `from re import compile` passes | What code a string holds is not syntax this check reads |
| A command a shell runs | gh or git is a command in any case, by a POSIX or a Windows path, with `.exe` or not: at the start of a string; after a new line, a shell's `;`, `&`, `|`, `(` or `{`; after a word that runs the next, such as `env`, `exec`, `then`, `nohup` or `xargs`, with its options; after a variable's assignment; ended by a space, the end or a shell's `;`, `&`, `|`, `)` or `}`; or quoted, opening the quote. A bytes literal is read as a string. RUNNERS gains `tools/hooks/shell.py`, which reads a command it is given and holds a pattern for git and gh | A shell runs each, `['sh', '-c', 'cd x && git push']` as surely as `'git push'` |
| A namespace package's `import *` | An import of all of a namespace package is refused, as one of a module's is | Its names are each a module's, and what they reach is not read |
| Still not held | A RUNNERS function that runs git with arguments it is given can be handed a write's by its caller. Eleven modules on main reach such a function, so listing its callers would list most of the harness, and holding each helper to read-only subcommands changes most of the twelve RUNNERS files, six of them hooks. A name given by a loop, a `with`, a container, a call's return or a starred part; `sys` or a module reached by `getattr` of a name not a literal, or by `unittest.mock.patch` given a module's name, or another Python run as a process; a command after a backtick, built from parts, or read from outside the code; a `match` capture's shadow, which Python 3.9 cannot parse and so refuses whole; an attribute set on a class from a class body in its own module. Text that runs nothing but reads as a command, `'~/.config/gh'` or a message that opens with Git, and an object's class counted, `type(self).n += 1`, are refused: each fails safe, and its message says what to do | The check is a net for code written plainly, as decision 0153 says. These need values the syntax does not give, or the helpers' own change, and are left to the review |

## Why

Those reads found these routes after that change's last fix round, and the reads of this change found more of the same kinds. Each but the runner's helper is a pattern the syntax names, so the check names it. On main only `tools/make_corpus.py` takes one of them, and it reads.
