# 1148. The acceptance port reads an issue's timeline to ten pages

Status: accepted. Extends decision 0234 with its bound on the acceptance port's read, as "adapters: bound the acceptance port's issue timeline read to ten pages" (issue 986) asks, part 2 of 2, as the Factory Builder ruled on 2026-11-20 (A). It restates the row of decision 1147 that it widens, now that the port says a cut; decisions 0234 and 1147 stand as they are.

## Decision

| What | Decided | Because |
|---|---|---|
| A cut acceptance read | `acceptance_bounded` in `facts/1` says the acceptance port cut the timeline of an issue the pull request closes, or that its branch binds it to, at its bound. The port gives it in every snapshot. Facts without it, read before it or an eval set's, read as not cut, and a value that is no truth value is a gap in acceptance. The Kernel defers a pull request so cut on its own code, `acceptance_bounded`, before any list read short and whatever `complete.acceptance` claims, and calls a person; a queued one is taken out, as for any read short | Read short and said no more, the pull request would wait in silence on a read that more comments never mend, and anyone can comment (the Claude and security reads of the bound, the Factory Builder's ruling (A) of 2026-11-20) |
| The issue a pull request closes | The acceptance port reads the timeline of each issue a pull request closes, or that its branch binds it to, to the same ten pages (`asks` in `adapters/acceptance.py`). A tenth page that names an eleventh leaves the pull request's acceptance not whole and cut, `acceptance_bounded`, and the eleventh is never asked. Every issue is read, so that a cut is said whatever another issue gave | Anyone can comment on the issue, and every open pull request that closes it reads its timeline again on every pass: the same amplification, by another port (the Claude read of the first part) |

## Why

Decision 1147 gave a cut acceptance read its own code and a person, with the port saying no cut yet. This part bounds the read, as decision 0234 bounds the issues port's, and says the cut wherever it happens, so that an outsider's comments cost a bounded number of requests and stop the pull request in plain view.
