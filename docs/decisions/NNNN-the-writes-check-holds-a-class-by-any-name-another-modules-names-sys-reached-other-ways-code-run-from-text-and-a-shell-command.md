# NNNN. The writes check holds a class by any name, another module's names set from outside, sys reached other ways, code run from text and a command a shell runs; a runner's helper stays the review's

Status: accepted. The Factory Builder's story of 2026-11-08, issue 640, "check_writes: routes still open after issue 596, a runner's helper, a class or instance reached through another name, sys.modules by getattr", raised by the reads of issue 596, "check_writes: further ways a write could be reached past the check, written to hide it". It amends decision 0167's row "Still not held".

## Decision

| What | Decided | Because |
|---|---|---|
| A class by any name for it | `tools/check_writes.py` reads a class through a module's constant that is it, `P = Port`, and through a name a function assigns it or takes it as a default for, `cls=Port`. An attribute set on `type(x)` or `x.__class__` is refused, as is `setattr` named as a value and `__setattr__`. A `for`, a `with` or a comprehension that sets an attribute sets it as an assignment does. A function under an `if` or a `try` is a function, and a nested `def` or `class`, or a caught exception's name, shadows a text constant | Each sets an attribute on a class as surely as `Port.w = ...` does, which decision 0167 refuses |
| Another module's names | An attribute or a key set from another module on what a module of the repo's defines or is, an instance, a dict, a function or the module itself, is refused, to anything but text. PATCHERS names who may: `tools/make_corpus.py`, which puts its recorder in `sim.world`'s place. A new one is the Maintainer's to allow, and an entry that sets nothing is refused | A caller reads what a module's own code gives its names; what another module sets on them is a value the syntax does not follow |
| sys reached other ways | Refused as a load by name: `sys` named as a value, `s = sys` or `getattr(sys, 'modules')`; its namespace, `sys.__dict__`; `sys` reached through another module, `os.sys` or `a.sys`, or imported from one, `from os import sys`; and `getattr` given `"sys"` or `"modules"` as a literal | Each reaches `sys.modules`, which decision 0167 refuses by its plain name |
| Code run from text | `exec`, `eval` and `compile`, named anywhere outside the tests, are refused | What code a string holds is not syntax this check reads |
| A command a shell runs | gh or git is a command in any case, by a POSIX or a Windows path, with `.exe` or not: at the start of a string, after a shell's `;`, `&`, `|` or `(`, after `env` or a variable's assignment, or quoted as a word. A bytes literal is read as a string | A shell runs each, `['sh', '-c', 'cd x && git push']` as surely as `'git push'` |
| A namespace package's `import *` | An import of all of a namespace package is refused, as one of a module's is | Its names are each a module's, and what they reach is not read |
| Still not held | A RUNNERS function that runs git with arguments it is given can be handed a write's by its caller. Eleven modules on main reach such a function, so listing its callers would list most of the harness, and holding each helper to read-only subcommands changes eleven files, five of them hooks. A class or an object reached through a loop's variable, a container or a call's return; `sys` reached by `getattr` of a name not a literal; a command after a backtick, built from parts, or read from outside the code. Text that runs nothing but holds gh or git as a command, `'~/.config/gh'` or a message that opens with git, is refused: it fails safe, and its message names RUNNERS | The check is a net for code written plainly, as decision 0153 says. These need values the syntax does not give, or the helpers' own change, and are left to the review |

## Why

Those reads found these routes after that change's last fix round. Each but the runner's helper is a pattern the syntax names, so the check names it. On main only `tools/make_corpus.py` takes one of them, and it reads.
